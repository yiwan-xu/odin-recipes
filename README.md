### Odin Recipes
In this project, I include recipes that are commonly seen in Italian restaurants, named "Italian Infusions", which highlight different specialities of the recipes and the ingredients and steps to make each dish.

By completing this project, I have been able to grasp the uses of key elements such as headers `<h1>`, images `<img>`, links to each separate page `<a>`, and using paragraphs and lists to build the basic structure for the website.

After building my understanding on CSS syntax and on the box structure, I improved the style of the website by utilising different classes and id's in order to change font styles, image positioning, display settings to suit the style of the website.
